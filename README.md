# eFootball 2027 PC Offline MyClub Mod

## 中文

Windows PC 离线 MyClub 养成版，包含球员签约、培养及比赛奖励。部分页面目前仅提供中文。

1. 从本仓库的 Releases 下载主包的四个分卷 `efootball2027-pc-offline-myclub-v1-20261118-base.7z.001` 至 `efootball2027-pc-offline-myclub-v1-20261118-base.7z.004`，放在同一个文件夹中。
2. 用 7-Zip 打开 `.001` 并解压到你选定的安装位置。其余分卷会自动读取。
3. 下载 `efootball2027-pc-offline-myclub-v1-20261119-cumulative-update.7z`。退出游戏，把升级包解压到主包解压时选定的同一个位置，让包内的 `发布` 文件夹合并到现有安装，并按提示替换同名文件。已有存档可以先备份。
4. 在 `发布` 文件夹双击 `启动养成版游戏.exe`。游戏随附的 `使用说明.html` 提供更多说明。

已安装 2026-11-18 V1 的玩家可以直接从第 3 步开始。

## English

An offline MyClub progression mod for Windows PC, with player signings, development, and match rewards. Some pages are currently available only in Chinese.

1. Download all four base archive volumes from this repository's Releases, from `efootball2027-pc-offline-myclub-v1-20261118-base.7z.001` through `efootball2027-pc-offline-myclub-v1-20261118-base.7z.004`. Keep them in the same folder.
2. Open `.001` with 7-Zip and extract it to your chosen installation location. The other volumes are read automatically.
3. Download `efootball2027-pc-offline-myclub-v1-20261119-cumulative-update.7z`. Close the game, then extract the update to the same location you selected for the base package. Merge its `发布` folder with the existing installation and replace matching files when prompted. Back up any existing saves before updating.
4. In the `发布` folder, double-click `启动养成版游戏.exe` to launch the game. See the included `使用说明.html` for more information.

If you already have the November 18, 2026 V1 base installed, start at step 3.
